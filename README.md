# Sound-UI-Animation-in-roblox-Studio
Підводимо підсумки. Я зрозумів основний алгоритм створення анімацій; зрозумів, що для кращої роботи з об'єктами їх AnchorPoint повинен бути в центрі; налаштовувати розміри інтерфейсу краще всього у відсотках по відношенню до екрана, а не просто зробити його конкретним розміром у пікселях. Звук в залежності від свого знаходження звучить по різному.
Весь інтерфейс робиться в папці StarterGUI а коди для елементів в локальних скриптах що лежать в середині об'єктів інтерфейсу.
